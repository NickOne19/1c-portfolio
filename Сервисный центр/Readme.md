# Пет-проект: «Сервисный центр по ремонту техники»

## Описание проекта

**«Сервисный центр по ремонту техники»** —  проект на платформе **1С:Предприятие 8.3**, предназначенный для автоматизации работы сервисного центра, который занимается диагностикой и ремонтом техники.

Решение позволяет организовать работу с клиентами и устройствами, регистрировать заказы на ремонт, учитывать выполненные работы и использованные запчасти, контролировать складские остатки и отслеживать этапы выполнения заказов.

Проект разработан в рамках самостоятельного изучения разработки на платформе 1С:Предприятие 8.3 и предназначен для практического применения знаний о прикладных объектах, документах, регистрах, запросах и отчётах.

## Цель проекта

Разработать прикладное решение для автоматизации основных бизнес-процессов сервисного центра:

- ведение базы клиентов и обслуживаемых устройств;
- оформление приёма техники в ремонт;
- регистрация выполненных ремонтных работ;
- учёт использованных запчастей и складских остатков;
- контроль статусов и сроков выполнения заказов;
- автоматический расчёт стоимости ремонта;
- формирование печатных форм и аналитических отчётов.

## Функциональные возможности

### 1. Ведение справочной информации

Для хранения основных данных предусмотрены справочники:

- **Клиенты** — информация о клиентах сервисного центра;
- **Устройства** — сведения о технике, принимаемой на обслуживание;
- **Сотрудники** — информация о сотрудниках;
- **ВидыРемонтныхРабот** — перечень услуг и ремонтных операций;
- **Запчасти** — номенклатура запчастей, используемых при ремонте.

### 2. Приём техники в ремонт

Документ **«Приём техники в ремонт»** предназначен для регистрации обращения клиента.

При оформлении заказа указываются:

- клиент;
- устройство;
- дата приёма;
- описание неисправности;
- ответственный сотрудник;
- планируемый срок выполнения.

Документ фиксирует поступление техники в сервисный центр и служит основанием для дальнейшего оформления ремонта.

### 3. Оформление ремонта

Документ **«Ремонт»** используется для регистрации выполненных работ и списания запчастей, использованных при восстановлении техники.

В документе предусмотрены две табличные части:

**Работа**
- выполненные ремонтные работы;
- стоимость каждой работы.

**Запчасти**
- использованные запчасти;
- цена;
- количество;
- сумма по каждой позиции.

При заполнении документа предусмотрено автоматическое заполнение цен на основании регистра сведений **«СтоимостьУслуг»** и регистра сведений **«СтоимостьЗапчастей»**.

Итоговая стоимость ремонта рассчитывается автоматически с учётом стоимости выполненных работ и использованных запчастей.

### 4. Учёт складских остатков

Для контроля наличия запчастей используется регистр накопления **«ОстаткиТоваров»**.

Предусмотрены следующие механизмы:

- учёт количества запчастей на складе;
- изменение остатков при использовании запчастей в ремонте;
- контроль наличия запчастей перед проведением документа;
- предотвращение списания количества, превышающего доступный остаток.

Это позволяет поддерживать актуальные сведения о наличии запчастей и снижать риск оформления ремонта при недостатке необходимых комплектующих.

### 5. Контроль состояния ремонта

Для отслеживания этапов выполнения заказа предусмотрен регистр сведений **«ИсторияСтатусовРемонта»**, предназначенный для хранения истории изменения статусов ремонта.

Используются следующие статусы:

- **Принят** — техника зарегистрирована в сервисном центре;
- **На диагностике** — выполняется проверка неисправности;
- **В ремонте** — выполняются ремонтные работы;
- **Готов** — ремонт завершён;
- **Выдан** — техника возвращена клиенту;
- **Отменён** — заказ отменён.

История статусов позволяет отслеживать ход выполнения заказа и получать информацию о текущем состоянии ремонта.

### 6. Выдача техники клиенту

При завершении ремонта необходимо зафиксировать готовность заказа, выдачу устройства клиенту и факт оплаты.

Информация о завершении заказа позволяет контролировать выполнение обязательств перед клиентом и учитывать завершённые ремонты при формировании отчётности.

### 7. Печатные формы

Предусмотрена печатная форма **«Акт приёма техники в ремонт»**.

Акт предназначен для документального подтверждения приёма устройства и содержит основные сведения о заказе, клиенте, устройстве, неисправности и планируемом сроке выполнения ремонта.

## Отчётность

В рамках проекта предусмотрена разработка следующих отчётов:

| Отчёт | Назначение |
|---|---|
| **Заказы в ремонте** | Просмотр заказов с возможностью отбора по периоду и статусу |
| **Остатки запчастей** | Получение информации о текущем количестве запчастей на складе |
| **Выручка сервисного центра** | Анализ стоимости выполненных работ и использованных запчастей за выбранный период |

## Используемые технологии

- **Платформа:** 1С:Предприятие 8.3;
- **Язык разработки:** встроенный язык 1С;
- **Запросы:** язык запросов 1С;
- **Отчётность:** система компоновки данных (СКД);
- **Хранение данных:** справочники, документы, регистры сведений и регистры накопления;
- **Печатные формы:** табличные документы и макеты.

## Практические навыки

В ходе разработки проекта отрабатываются следующие навыки:

- получение данных с помощью языка запросов;

- работа с движениями документов;

- создание печатных форм;
- обработка ошибок и проверка корректности вводимых данных.
