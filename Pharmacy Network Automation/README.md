Вам пришел заказ на разработку прикладного решения для автоматизации сети аптек.

Сеть аптек имеет филиалы по всему городу.

Необходимо:

●      Хранить цены лекарств. Цены единые для всех филиалов.

●      Предусмотреть механизмы для закупки и продажи лекарств.

●      Хранить остатки лекарств. В каждом филиале собственный учет лекарств

●      Учитывать остатки лекарств на складе. При проведении продажи лекарств не давать списывать лекарства, если их нет в наличии в филиале.

●      Предусмотреть автоматическое заполнение цен при продаже лекарств.

●      Вывести информацию по продажам лекарств за месяц. В информации указать: лекарство, количество и сумму продаж.
