## Кадровый учёт

### В информационной базе необходимо хранить данные по кадровому учёту.

Созданы два документа: «Приём на работу» и «Увольнение сотрудника».

В документе «Приём на работу» - физ. лицо, должность и оклад.

В документе «Увольнение сотрудника» - физ. лицо и причину увольнения.

Реализован отчёт по действующим сотрудникам.

Для справочника «Физические лица»:
выведена информация, является ли физическое лицо действующим сотрудником;

создан механизм хранения информации о трудовой деятельности. Информация включает в себя следующие данные: место работы, должность, дата приёма на работу, дата увольнения.
